push-wp Rust

将本地 Markdown 文件发布到 WordPress。

编辑预览 → 填表设置元数据 → 上传本地图片 → 发布 / 更新文章

使用方式：正文直接写 Markdown（无需 front-matter），点「发布」后填写标题、固定链接、分类、标签、摘要、头图等表单信息。
